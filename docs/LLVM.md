# Toolchain Version in NDK Releases

The latest version of this document is available at
https://android.googlesource.com/platform/ndk/+/mirror-goog-main-ndk/docs/LLVM.md.

In each NDK release, we ship the LLVM toolchain as a prebuilt so you can find
which toolchain version was in which NDK release. To understand how the
toolchain is deployed in the NDK, you should read the [Toolchains
file](https://android.googlesource.com/platform/ndk/+/mirror-goog-main-ndk/docs/Toolchains.md).
